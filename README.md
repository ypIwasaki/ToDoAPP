# ToDoAPP

Android 16以降に対応した、個人利用向けのローカルToDoアプリです。タスクとサブタスク、期限通知、一覧、月間カレンダーに加え、選択したキャラクターを端末画面上に表示できます。

## 主な機能

- タスクの追加・編集・削除・完了
- タイトルとメモの登録
- サブタスクの追加・編集・削除・完了
- 期限の日付・時刻設定
- 「期限時」「10分前」「1時間前」「1日前」の通知
- 未完了・完了・すべてのタスクの絞り込み
- 月間カレンダーで期限日ごとのタスク件数と内容を確認
- システム設定に応じたライト／ダークテーマ
- アプリ終了中およびDoze中の通知
- 画面点灯中のヘッドアップ通知と、スリープ中のロック画面・全画面通知
- 端末再起動、アプリ更新、日時・タイムゾーン変更後の通知再登録
- ほかのアプリの使用中も維持されるキャラクター表示
- システムバーや画面切り欠きを避けたキャラクターの自動移動
- 移動中の6コマ歩行アニメーションと、停止中の6種類の表情
- キャラクターのサイズと不透明度をアプリ内で調整・保存
- キャラクターの自動移動をアプリ内で切り替え・保存
- キャラクターのタップでアプリを開き、ドラッグで表示位置を変更・保存
- 長押しメニューからアプリ起動、自動移動の一時停止・再開、キャラクターの非表示
- タスク登録・完了・期限切れ・期限通知に連動する表情と吹き出し
- 吹き出しからタスク表示、完了、取り消し、10分／1時間のスヌーズ
- タスク概要の定期案内と、案内頻度・通知しない時間帯の設定
- タップ・ドラッグ操作と、ドラッグ後に自動移動を再開するまでの時間設定

## データとプライバシー

タスクはRoomデータベースを使って端末内だけに保存します。ログイン、外部アカウント連携、ネットワーク通信、クラウド同期はありません。OSのクラウドバックアップと端末間転送からもアプリデータを除外しています。

アプリを削除すると、保存したタスクも削除されます。

## 開発環境

1. Android Studioでこのフォルダを開きます。
2. SDK ManagerからAndroid SDK Platform 36とAndroid SDK Build-Tools 36をインストールします。
3. Gradle JDKにJDK 17を選択します。
4. Android 16以降の実機またはエミュレーターを選び、`app`を実行します。

コマンドラインで確認する場合:

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

生成されたデバッグAPKは次に出力されます。

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 通知について

期限通知を確実に受け取るには、Androidの「通知」「アラームとリマインダー」「全画面通知」の3つを許可してください。設定が不足している場合はタスク一覧に案内カードを表示します。

通知は、Doze中も発火できる正確な`AlarmManager`予約と、端末再起動後も維持されるWorkManagerの予約を併用します。両方が動作しても同一タスクの通知は一度だけ表示されます。端末再起動、アプリ更新、システム日時・タイムゾーン変更、正確なアラーム権限の再許可後には、保存済みタスクから通知を再登録します。

画面点灯中はヘッドアップ通知を表示し、スリープ中はロック画面へタスク名と期限を表示します。「全画面通知」が許可されている場合は画面を点灯して専用の期限画面を開き、未許可の場合もAndroidの拡大ヘッドアップ通知へフォールバックします。表示方法は端末の通知設定が優先されます。

Androidの「強制停止」を実行すると、OSがアプリを停止状態にするため通知できません。アプリを一度手動で起動すると再登録します。また、バッテリー設定が「制限付き」の場合はバックグラウンド通知が抑止されるため、アプリ内の案内から設定を変更してください。

## キャラクター表示について

下部ナビゲーションの「キャラ」を開き、Androidの「他のアプリの上に重ねて表示」を許可すると、採用したキャラクターを画面右下から表示します。表示中はアプリをバックグラウンドへ移しても維持され、画面の安全領域内からランダムに行き先を選び、6コマの歩行アニメーションで移動します。進行方向に合わせて画像を左右反転し、目的地で停止すると6種類の表情からランダムに切り替わります。アプリ内のボタンまたは常駐通知の「非表示にする」から停止できます。

キャラ画面のスライダーから、サイズを50〜160%、不透明度を20〜100%の範囲で5%刻みに変更できます。「自動移動」と「タップ・ドラッグ操作」を個別に切り替えられます。キャラクターをタップするとアプリを開き、ドラッグすると安全領域内で位置を変更して保存します。長押しすると、アプリを開く、自動移動を一時停止・再開する、キャラクターを非表示にするメニューを表示します。

タスクの登録・完了・期限切れ・期限通知を検知すると、内容に応じた表情と吹き出しを表示します。吹き出しから対象タスクを開く、完了にする、完了を取り消す、10分後または1時間後に再通知する操作ができます。同一内容の吹き出しは30分間抑制します。定期案内の頻度は「なし／静か（6時間）／標準（3時間）／にぎやか（1時間）」から選択でき、通知しない時間帯も設定できます。キャラクターが非表示または画面消灯中の場合、定期案内は通常の通知で表示します。

消費電力を抑えるため、画面消灯中は移動と歩行アニメーションを一時停止し、画面点灯時に自動で再開します。ドラッグ終了後は、設定した5〜60秒の待機時間を経て自動移動を再開します。表示と操作の設定は端末内に保存し、次回表示時にも引き継ぎます。

## プロジェクト構成

```text
app/src/main/java/com/example/todoapp/
├── data/          Roomエンティティ、DAO、リポジトリ
├── model/         編集用モデル、通知タイミング
├── mascot/        キャラクター画像処理、画面オーバーレイ表示
├── notification/ 通知予約、表示、重複防止、予約復旧
└── ui/            タスク一覧、編集、カレンダー、キャラクター設定、テーマ
```

## 現在の範囲

繰り返しタスク、クラウド同期、共有、ユーザー登録、外部カレンダー連携、キャラクター素材のユーザー選択には対応していません。
