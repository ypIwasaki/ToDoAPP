# ToDoAPP

Android 16以降に対応した、個人利用向けのローカルToDoアプリです。タスクとサブタスク、期限通知、一覧、月間カレンダーを一つのアプリで管理できます。

## 主な機能

- タスクの追加・編集・削除・完了
- タイトルとメモの登録
- サブタスクの追加・編集・削除・完了
- 期限の日付・時刻設定
- 「期限時」「10分前」「1時間前」「1日前」の通知
- 未完了・完了・すべてのタスクの絞り込み
- 月間カレンダーで期限日ごとのタスク件数と内容を確認
- システム設定に応じたライト／ダークテーマ
- アプリ終了中およびDoze中の通知
- 画面点灯中のヘッドアップ通知と、スリープ中のロック画面・全画面通知
- 端末再起動、アプリ更新、日時・タイムゾーン変更後の通知再登録

## データとプライバシー

タスクはRoomデータベースを使って端末内だけに保存します。ログイン、外部アカウント連携、ネットワーク通信、クラウド同期はありません。OSのクラウドバックアップと端末間転送からもアプリデータを除外しています。

アプリを削除すると、保存したタスクも削除されます。

## 技術構成

- Kotlin 2.3.20
- Jetpack Compose / Material Design 3
- Room 2.8.4
- AlarmManager + WorkManager 2.11.2 + NotificationCompat
- Android Gradle Plugin 8.13.2
- Gradle 8.13
- Java 17
- `minSdk = 36` / `targetSdk = 36` / `compileSdk = 36`

## 開発環境

1. Android Studioでこのフォルダを開きます。
2. SDK ManagerからAndroid SDK Platform 36とAndroid SDK Build-Tools 36をインストールします。
3. Gradle JDKにJDK 17を選択します。
4. Android 16以降の実機またはエミュレーターを選び、`app`を実行します。

コマンドラインで確認する場合:

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

生成されたデバッグAPKは次に出力されます。

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 通知について

期限通知を確実に受け取るには、Androidの「通知」「アラームとリマインダー」「全画面通知」の3つを許可してください。設定が不足している場合はタスク一覧に案内カードを表示します。

通知は、Doze中も発火できる正確な`AlarmManager`予約と、端末再起動後も維持されるWorkManagerの予約を併用します。両方が動作しても同一タスクの通知は一度だけ表示されます。端末再起動、アプリ更新、システム日時・タイムゾーン変更、正確なアラーム権限の再許可後には、保存済みタスクから通知を再登録します。

画面点灯中はヘッドアップ通知を表示し、スリープ中はロック画面へタスク名と期限を表示します。「全画面通知」が許可されている場合は画面を点灯して専用の期限画面を開き、未許可の場合もAndroidの拡大ヘッドアップ通知へフォールバックします。表示方法は端末の通知設定が優先されます。

Androidの「強制停止」を実行すると、OSがアプリを停止状態にするため通知できません。アプリを一度手動で起動すると再登録します。また、バッテリー設定が「制限付き」の場合はバックグラウンド通知が抑止されるため、アプリ内の案内から設定を変更してください。

## プロジェクト構成

```text
app/src/main/java/com/example/todoapp/
├── data/          Roomエンティティ、DAO、リポジトリ
├── model/         編集用モデル、通知タイミング
├── notification/ 通知予約、表示、重複防止、予約復旧
└── ui/            タスク一覧、編集、カレンダー、テーマ
```

## 現在の範囲

初版には繰り返しタスク、クラウド同期、共有、ユーザー登録は含まれていません。
